Section 5

Registration Quality

Technical interpretation of the three primary quality indicators.

Inlier Ratio

—

Percentage of matched feature pairs that remain geometrically consistent under the estimated homography after RANSAC filtering. A high inlier ratio indicates strong geometric agreement between the two images.

RMSE (Reprojection Error)

—

Root mean square error of the geometric reprojection over RANSAC inlier correspondences, measured in pixels. Quantifies the average residual misalignment of retained feature pairs.

Spatial Coverage

—

Fraction of a 4×4 regular grid over the reference image that contains at least one RANSAC inlier correspondence. Indicates how broadly the valid correspondences are distributed across the image area.

Section 7

Technical Methodology

Implementation details of the current baseline pipeline.

Component Method / Parameter Detail
Feature Detector cv2.SIFT_create() Scale-Invariant Feature Transform — detects local extrema in scale space, robust to scale and rotation changes.
Descriptor 128-dimensional float Gradient orientation histogram over a 4×4 spatial grid of 4×4 cells, each with 8 orientation bins.
Matcher cv2.BFMatcher(NORM_L2) Brute-force k-NN matcher (k=2) using Euclidean distance over descriptor vectors.
Match Filtering Lowe ratio = 0.75 A match is retained only if its distance is less than 75% of the second-best match distance.
Outlier Rejection cv2.findHomography(RANSAC, 5.0px) RANSAC with reprojection threshold 5.0 px. Iteratively selects a minimal sample set and counts inliers to identify the consensus model.
Transformation Model Homography H ∈ ℝ³ˣ³ 8-DOF projective transformation mapping source image coordinates to reference image coordinates.
Warping cv2.warpPerspective() Applies the estimated homography H to warp the source image to the reference frame.
Quality — RMSE √mean(‖H·src_i − ref_i‖²) Average reprojection error of RANSAC inlier pairs under the final homography. Measured in pixels.
Quality — Spatial Coverage 4×4 grid occupancy Number of 4×4 grid cells in the reference image containing ≥1 inlier correspondence, divided by 16.
Note — Baseline Pipeline: This prototype implements a classical SIFT-based monocular image registration pipeline as an MVP baseline. For production multi-modal registration (OHRC ↔ TMC-2 ↔ IIRS cross-spectral correspondence), the pipeline can be extended with learned feature descriptors (SuperPoint, DISK), cross-modal matchers (LightGlue, LoFTR), and band-specific normalisation.
